# 前端页面优化与验收

日期：2026-10-14（Asia/Shanghai）。

本轮保留现有墨绿与浅灰视觉方向，重点优化阅读、导航、键盘操作和异常恢复。开始时前端已有未提交改动，本轮在现有工作基础上增量修改。

## 发现与落地

| 原问题 | 已实现的改进 | 主要入口 |
| --- | --- | --- |
| 正文说明和侧栏信息偏小、颜色偏浅 | 提升主要说明文字字号、行高和颜色对比，长标题与路径可换行 | `apps/web/src/styles.css` |
| 窄窗口侧栏只显示图标，工作项难以识别，部分入口隐藏 | 增加完整导航抽屉；手机隐藏图标栏，使用顶部导航按钮；保留工作空间、工作项和产物名称 | `App.tsx`、`styles.css` |
| 工作项增多后查找效率下降 | 增加当前空间工作项搜索和无匹配提示；切换空间重置搜索 | `App.tsx` |
| 页签只有按钮语义，缺少键盘切换 | 使用 tablist/tab/tabpanel；方向键、Home、End 切换，单一页签进入 Tab 顺序 | `App.tsx` |
| 弹窗缺少焦点循环，背景可被键盘访问 | 弹窗和导航抽屉约束焦点，背景 inert，Escape 关闭，关闭后返回触发入口；打开前记录入口，避免 inert 提前移走焦点 | `useModalFocus.ts`、`Dialogs.tsx`、`App.tsx` |
| 刷新异常可能无人处理，失败页面一直转圈 | 明确读取状态与失败状态，区分首次加载和工作项加载失败，提供重试；手动刷新统一捕获异常并清理恢复后的错误通知 | `App.tsx`、`api.ts` |
| 补丁读取失败始终显示加载中，旧请求可能覆盖新候选 | 区分加载、失败、空差异和成功；失败可重试；候选切换清空旧补丁，忽略过期请求结果 | `CodeView.tsx` |
| 文档草稿写入浏览器存储失败会中断编辑 | 增加窗口内草稿备份、存储失败提示和跨页恢复；未保存时离开窗口提示；保存期间正文只读，冲突禁止直接保存 | `Documents.tsx` |
| 流程进度和当前步骤缺少辅助技术语义 | 增加 progressbar 和当前步骤 aria-pressed | `Flow.tsx` |

本轮不引入新依赖。Maka 的执行底座、正式发布校验和打包政策保持现有配置。

## 验证结果

- `npm run typecheck` 通过，最终 `npm run build` 再次通过类型检查与生产构建。
- `npm test`：40 项通过，0 失败，0 跳过，包括真实 Maka Host 本地协议夹具。
- 五个页面（开发流程、需求输入、文档产物、代码与验证、运行记录）分别在 390、800、1280 像素宽度下检查：15 个组合均无页面级横向溢出。
- 实际浏览器验证工作项搜索、无匹配提示、导航开关、方向键及 Home/End 页签切换、弹窗 Tab/Shift+Tab 循环、Escape 关闭、桌面与抽屉入口焦点恢复。
- 临时阻断 bootstrap、工作项快照及补丁请求，验证失败提示、停止转圈和重试恢复。
- 临时模拟文档存储配额不足，验证提示、切换页面后的草稿与提示恢复；恢复原正文，未提交测试修订。
- 历史文档版本为只读；最后使用独立验收数据目录启动最终生产构建，验证生产页面的页签、焦点恢复和页面布局。
- 浏览器网络阻断和存储故障注入已撤销，窗口尺寸覆盖已重置。开发热更新期间修改 hook 依赖数组产生过一次 React 热更新诊断，最终生产页面未出现新的控制台错误。

## 后续值得推进的方向

1. 需求和文档增加 Markdown 渲染预览，以及按段落定位的实际差异视图。现有比较仍为两列全文。
2. 运行记录增加步骤、状态筛选与长记录分页。当前只改进了可读性与响应式展示。
3. 收敛原有 CSS 中的重复规则和硬编码字号，将状态色、正文色和间距统一为设计变量；本轮为增量样式调整。
