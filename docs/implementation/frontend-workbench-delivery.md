实际验证了上下文抽屉切换到运行详情、Escape 关闭、焦点归还和 body 滚动恢复。多项待处理进入去重列表；历史修订保持只读，Markdown 目录和真实差异可以使用。

| 故障与边界 | 验证内容 |

## C 当前边界与后续能力

P3 的逐 Token 输出、完整工具时间线仍按方案后置。当前面板只使用底座已提供的状态、交互与最终输出。未增加独立 harness 选择、注册表或额外适配器。

运行历史采用摘要列表与按需详情。需求历史与文档修订全文仍保留在快照中，便于草稿冲突和版本审阅；本轮未将它们也改成逐份正文加载。

评论继续使用文本锚点，重复匹配时允许选择。稳定段落 ID 和跨版本迁移、暗色主题及任意源码文件浏览留在后续范围。

用户审阅接口与模型复核材料独立。界面正文默认按 64 KiB 分块，补丁有明确截断说明。模型复核原有单文件 512 KiB、总材料 1 MiB 限制继续生效；截断展示不能作为完整复核证据。

本轮重建了开发版桌面资源，未重打安装包。Windows 桌面已验证，macOS 仍需在对应平台验收。未提交或发布分支；进入任务时已有的本地改动保留在当前工作树。

## D Claude Code 复核入口

优先检查接纳只读断言、集成期间的互斥和 checkpoint 后复验。检查用户差异路径是否受边界与排除规则约束，分块是否核对候选及文件哈希。

检查 SSE 是否只在刷新成功后确认游标。被后续刷新替代的请求需等待最新请求结果，不能被当作成功同步。事件接收 ID 与业务快照同步状态分别处理。

检查桌面 IPC 的 trustedSender、视图字段白名单与文件上限。位置记录只保存对象标识及展示枚举，不能保存文档正文或凭据。

检查各资源 scope 是否保护相同版本操作。原执行控制待确认时，新派发不能通过另一条入口绕过锁；human 接纳与代码页共用候选锁。

检查草稿队列是否保留真实外部冲突，终态是否关闭写入口。确认完整需求、章程、执行身份、原始输出和双视角证据仍能查看。

本轮完成了内部只读复查，未调用外部 Claude Code。请以当前工作树、上述测试和 QA 报告作为后续复核依据。
