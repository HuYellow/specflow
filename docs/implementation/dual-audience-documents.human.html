01

给 AI：完整 Markdown

  • 保留稳定 ID、约束、异常、验收和上游追溯。
  • 普通下游步骤继续使用完整原文与原哈希。
02

给人：HTML 阅读页

  • 界面默认显示简报，可切换完整执行文档和版本比较。
  • 人类阅读文档仅提供 HTML，可离线打开。
03

同一来源

  • 简报绑定来源修订与 SHA-256，正文更新后不沿用旧简报。
  • 导入与历史文档提供标注为原文摘录的阅读视图。
04

接纳与交付

  • 接纳后写出 .md 和 .human.html，两份文件随最终代码纳入 Git。
  • 写入失败保留操作记录供重试；启动时可补齐 HTML 阅读文件。
05

复核与验证

  • 两轮独立复核比较简报与正文，检查矛盾、无依据新增和虚假成功声明。
