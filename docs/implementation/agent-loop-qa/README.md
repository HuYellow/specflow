# Agent loop UI 验收

`report.json` 和截图由 `scripts/agent-loop-ui-smoke.mjs` 生成。使用 Node.js 24、已安装的 Google Chrome 和项目依赖运行：

```sh
node --import tsx scripts/agent-loop-ui-smoke.mjs
```

脚本在系统临时目录构建前端并创建独立示例仓库、数据库和本地服务，结束后删除临时目录。模型执行均使用确定性 SandboxBackend 或可停止的本地协议夹具，没有调用真实模型，没有改动业务工作空间。

公开截图使用固定遮罩隐藏侧栏和工作空间选择器中的机器特定临时目录路径，避免包含本机用户名。遮罩只应用于截图捕获，不改动生产界面、页面状态或交互检查；报告记录了遮罩选择器。

本次通过 1440×1000 与 390×1000 的 8 个页面状态，检查横向溢出、英文 UI 中的中文残留和浏览器异常。覆盖部分 Token、未知费用、停止未确认、上下文材料、默认手动模式、显式开启自动修订、停止自动推进和停止修订。

操作验收还实际停止了临时验证命令的 Node.js 进程。验证进程确认对话框取消时没有发出确认请求；确认时提交当前版本与明确处理理由。自动化活动期间不能从 UI 重复手动派发。没有恢复能力的历史尝试不会启用恢复按钮。

这些结果验证界面、操作契约和确定性控制行为，不证明真实模型的修复质量或成本收益。DSH 复用相同运行事实、自动化和验证恢复组件，另由插件类型检查、API 测试与共享组件渲染测试覆盖；本目录截图来自独立桌面 Web 工作台。
